# Drope Tattoo

Site oficial do Drope Tattoo — arte autoral na pele. (@drope.tattoo777)

## Stack

- HTML/CSS/JS puro, empacotado com [Vite](https://vitejs.dev/)
- Deploy automático na [Vercel](https://vercel.com)

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
```

Output em `dist/`.

## Deploy

Deploy automático: todo `git push` na branch `main` dispara build e deploy em Production na Vercel.
